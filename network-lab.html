What this lab validates

Four eBGP connections, optional direct CE-to-CE iBGP, Local Preference, advertised IPv4 prefixes and reachability before, during and after a selected link failure.

FRR behavior only. Original vendor configuration syntax, BFD, filtering, prepend, MED, communities, maximum-prefix, VRFs and authentication are outside this pilot. No production performance or exact convergence claim is made.

02 · Run on your Linux lab host

The web service prepares the lab; a separate Linux host runs the virtual routers. Install Docker and Containerlab, extract the ZIP and run these commands inside its directory. The selected FRR image must be available to the host. Review the included README before starting.

sudo python3 runner.py start
sudo python3 runner.py baseline
sudo python3 runner.py fail
sudo python3 runner.py stop

Fail checks the baseline, disables the selected CE interface, collects evidence, then restores the interface. If the process is interrupted, use sudo python3 runner.py restore. Results are saved in results.json. The lab uses isolated virtual links; it does not connect to production devices.
