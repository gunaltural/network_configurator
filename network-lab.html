Model scope and inbound assumptions

Inbound is evaluated separately at each directly connected ISP for the selected CE prefix. An alternate CE advertises that prefix only while the owner CE and their interconnect are available. No link between ISPs or remote Internet observer is assumed. Equal AS paths use the connection ID for a deterministic single-path illustration; this is not a vendor tie-break or ECMP prediction. Provider Local Preference, filtering and other external policies may override prepend.

These changes affect the simulation only. Generated design configurations remain unchanged.
